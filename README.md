# AI-ҰСТАЗ — курс «ИИ на службе учителя»

## Русский

Готовый двуязычный контент-проект дистанционного курса из 36 микроуроков для учителей. Каждый урок рассчитан на короткое инструкционное видео продолжительностью 2–3 минуты и практическую работу.

### Состав проекта

- `course/course-map.md` — карта курса, треки, зависимости и результаты.
- `course/glossary.md` — двуязычный словарь терминов.
- `course/orchestra-assignments.md` — роли и порядок работы AI-агентов.
- `course/final-bank.yaml` — банк из 144 заданий для сборки итогового теста на 20–30 вопросов.
- `course/lessons/L01...L36/` — пакеты уроков.

Каждый пакет урока содержит:

- `work-order.yaml` — техническое задание;
- `lesson.md` — подробный текст RU/KZ;
- `video-script.md` — сценарий видео RU/KZ с таймкодами;
- `prompts.md` — библиотека копируемых промптов RU/KZ;
- `assignment.md` — практическая работа и рубрика;
- `quiz.yaml` — мини-тест или обоснованное отключение;
- `qa-report.md` — автоматический QA-чеклист.

### Перед публикацией

1. Заменить пометки `[НУЖНА ПРОВЕРКА]` фактическими названиями элементов актуального интерфейса Higgsfield Supercomputer.
2. Отдельно вычитать казахскую терминологию редактором-носителем языка.
3. Записать скринкасты по `video-script.md` и сверить фактическую длительность.
4. Перевести `status: draft/review` в `approved` только после ручной проверки.
5. Не добавлять персональные данные учеников в примеры и демонстрации.

### Проверка структуры

```bash
python validate_project.py
```

Генераторы сохранены в корне проекта, поэтому весь комплект можно воспроизвести и обновлять.

## Қазақша

Мұғалімдерге арналған 36 шағын сабақтан тұратын «ЖИ мұғалімге қызмет етеді» қашықтан оқыту курсының дайын екітілді контент-жобасы. Әр сабақ 2–3 минуттық нұсқаулық бейне мен практикалық жұмыстан тұрады.

### Жоба құрамы

- `course/course-map.md` — курс картасы, тректер, байланыстар және нәтижелер.
- `course/glossary.md` — екітілді терминдер сөздігі.
- `course/orchestra-assignments.md` — AI-агенттердің рөлдері мен жұмыс реті.
- `course/final-bank.yaml` — 20–30 сұрақтық қорытынды тест құрастыруға арналған 144 тапсырма банкі.
- `course/lessons/L01...L36/` — сабақ пакеттері.

Әр сабақ пакетінде:

- `work-order.yaml` — техникалық тапсырма;
- `lesson.md` — RU/KK толық мәтіні;
- `video-script.md` — таймкодтары бар RU/KK бейнесценарийі;
- `prompts.md` — көшіріп қолданылатын RU/KK промпттар кітапханасы;
- `assignment.md` — практикалық жұмыс және бағалау рубрикасы;
- `quiz.yaml` — шағын тест немесе оны қоспау негіздемесі;
- `qa-report.md` — автоматты QA чек-парағы.

### Жариялау алдында

1. `[ТЕКСЕРУ ҚАЖЕТ]` белгілерін Higgsfield Supercomputer интерфейсінің өзекті атауларымен ауыстыру.
2. Қазақша терминологияны тіл маманына бөлек тексерту.
3. `video-script.md` бойынша скринкаст жазып, нақты ұзақтығын өлшеу.
4. Қолмен тексерілгеннен кейін ғана `status: draft/review` күйін `approved` күйіне ауыстыру.
5. Мысалдар мен көрсетілімдерге оқушылардың жеке деректерін қоспау.

### Құрылымды тексеру

```bash
python validate_project.py
```

Жинақты қайта жасау және жаңарту үшін генераторлар жобаның түбірінде сақталған.
