# AI-ҰСТАЗ: ИИ на службе учителя

Двуязычный курс из 36 микроуроков по использованию Higgsfield Supercomputer в работе учителя.

Языки: русский и казахский.

Основные материалы курса находятся в каталоге `course/` после импорта.

## Для AI-агентов

Перед изменениями прочитайте `AGENTS.md`, `course/glossary.md` и соответствующий `course/lessons/Lxx/work-order.yaml`.

Не вводите и не добавляйте персональные данные учащихся.
