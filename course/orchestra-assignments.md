# Назначения оркестру / Оркестр тапсырмалары

## Общий контракт / Ортақ келісімшарт

Каждая роль получает `course-map.md`, `glossary.md`, соответствующий
`lessons/Lxx/work-order.yaml` и принятые артефакты prerequisites.
Әр рөл `course-map.md`, `glossary.md`, тиісті
`lessons/Lxx/work-order.yaml` және қабылданған prerequisite
артефактілерін алады.

Любое название кнопки, модели, режима, лимита, цены или экспорта
проверяется в актуальном Higgsfield Supercomputer. До проверки:
`[НУЖНА ПРОВЕРКА]` / `[ТЕКСЕРУ ҚАЖЕТ]`.

## 1. Автор текста / Мәтін авторы

**Выход / Шығыс:** `lessons/Lxx/lesson.md`.

- Создать параллельные RU/KK версии с одинаковыми целями, шагами,
  ограничениями, примерами и критериями.
- RU/KK нұсқаларын мақсаттары, қадамдары, шектеулері, мысалдары және
  өлшемшарттары бірдей етіп жасау.
- Дать короткие нумерованные шаги, ожидаемый результат, типичные ошибки
  и самопроверку.
- Қысқа нөмірленген қадамдар, күтілетін нәтиже, жиі қателер және
  өзін-өзі тексеруді беру.
- Использовать термины из глоссария; не выдумывать UI.
- Глоссарий терминдерін қолдану; UI элементтерін ойдан шығармау.
- Включить безопасность, фактчекинг, авторскую проверку и раскрытие роли ИИ.
- Қауіпсіздік, фактчекинг, авторлық тексеру және ЖИ рөлін ашуды қосу.

## 2. Сценарист видео / Видео сценарисі

**Выход / Шығыс:** `lessons/Lxx/video-script.md`.

- Максимальная длительность каждой языковой версии — 180 секунд.
- Әр тілдік нұсқаның ең ұзақ уақыты — 180 секунд.
- Структура: хук 0–15, демонстрация 15–135, мини-проверка и CTA 135–180.
- Құрылым: ілмек 0–15, көрсету 15–135, шағын тексеру және CTA 135–180.
- Для сцены указать таймкод, экранное действие, дикторский текст и подпись.
- Әр көрініске таймкод, экран әрекеті, диктор мәтіні және жазу беру.
- Человеческие визуалы показывают женщин-учителей; стиль светлый,
  минималистичный, с крупным контрастным текстом.
- Адам бар визуалдарда әйел мұғалімдер көрсетіледі; стиль ашық,
  минималистік, мәтін ірі және контраст.
- Не показывать реальные данные учеников.
- Оқушылардың нақты деректерін көрсетпеу.

## 3. Архитектор промптов и практики / Промпт пен практика архитекторы

**Выходы / Шығыстар:** `lessons/Lxx/prompts.md`,
`lessons/Lxx/assignment.md`.

- Создать уникальные P-ID и A-ID по work order.
- Work order бойынша бірегей P-ID және A-ID жасау.
- Промпты копируются целиком, используют Р-З-К-Ф/Р-Т-К-Ф и квадратные
  плейсхолдеры.
- Промпттер толық көшіріледі, Р-З-К-Ф/Р-Т-К-Ф және шаршы жақшадағы
  толтырылатын орындарды қолданады.
- Первый промпт создаёт черновик; второй выполняет аудит.
- Бірінші промпт жоба жасайды; екіншісі аудит жүргізеді.
- Практика задаёт наблюдаемый результат, тип вложения, доказательства,
  чек-лист и рубрику.
- Практика бақыланатын нәтиже, тіркеме түрі, дәлелдер, чек-парақ және
  рубриканы береді.
- Все входы синтетические или обезличенные.
- Барлық кірістер синтетикалық немесе иесіздендірілген.

## 4. Дизайнер оценивания и QA / Бағалау және QA дизайнері

**Выходы / Шығыстар:** `lessons/Lxx/quiz.yaml`,
`lessons/Lxx/qa-report.md`.

- Создать 3 ситуационных Q-ID с ключами, объяснениями и обратной связью.
- Кілттері, түсіндірмелері және кері байланысы бар 3 жағдаяттық Q-ID жасау.
- Проверять применение, безопасность и качество, а не названия кнопок.
- Батырма атауларын емес, қолдануды, қауіпсіздікті және сапаны тексеру.
- Проверить RU/KK-паритет, ID, ссылки, вложение, факты, ключи,
  доступность и отсутствие персональных данных.
- RU/KK теңдігін, ID-лерді, сілтемелерді, тіркемені, фактілерді,
  кілттерді, қолжетімділікті және дербес деректердің жоқтығын тексеру.
- QA PASS разрешён только после устранения blockers.
- QA PASS тек блоктаушы ақаулар түзетілгеннен кейін беріледі.

## Имена и стабильные ID / Атаулар және тұрақты ID

- Уроки / Сабақтар: `L01`–`L36`.
- Промпты / Промпттер: `P-Lxx-01`, `P-Lxx-02`.
- Задание / Тапсырма: `A-Lxx-01`.
- Вопросы / Сұрақтар: `Q-Lxx-01`–`Q-Lxx-03`.
- Производственные файлы / Өндірістік файлдар:
  `lesson.md`, `video-script.md`, `prompts.md`, `assignment.md`,
  `quiz.yaml`, `qa-report.md`.

## Очередь / Кезек

1. L01–L06 — фундамент / негіз.
2. L07–L13 — тексты и данные / мәтіндер және деректер.
3. L14–L19 — визуалы / визуалдар.
4. L20–L24 — презентации / презентациялар.
5. L25–L29 — видео / видео.
6. L30–L34 — интерактивы / интерактивтер.
7. L35–L36 — платформы и приложения / платформалар және қолданбалар.

Следующий пакет выходит в production после PASS обязательных
prerequisites. Келесі пакет міндетті prerequisites PASS алғаннан кейін
production кезеңіне өтеді.

## Blockers / Блоктаушы ақаулар

- персональные данные учеников / оқушылардың дербес деректері;
- несуществующая или непроверенная функция без маркировки /
  белгіленбеген жоқ немесе тексерілмеген функция;
- неверный ключ или учебный факт / қате кілт немесе оқу фактісі;
- несовпадение RU и KK / RU және KK сәйкессіздігі;
- отсутствующее или неоткрывающееся вложение /
  жоқ немесе ашылмайтын тіркеме;
- сценарий длиннее 180 секунд / сценарий 180 секундтан ұзақ;
- недоступный визуал или видео без текстового эквивалента /
  қолжетімсіз визуал немесе мәтіндік баламасы жоқ видео.
