# L19: Проверенная учебная карточка / Тексерілген оқу карточкасы

## Русский

### P-L19-01

**Эквивалент / Баламасы:** P-L19-07

**Назначение / Мақсаты:** Быстро получить первый вариант результата урока «Проверенная учебная карточка».

**Когда применять / Қашан қолдану:** В начале работы, чтобы получить черновик и увидеть, каких уточнений не хватает.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Первый структурированный вариант: учебную карточку после предметной и языковой проверки.

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Результат соответствует теме и цели; обязательное условие: Приложены исходная версия, список найденных ошибок, исправленная карточка и отметка о ручной проверке фактов.

```text
Создай учебную карточку после предметной и языковой проверки.

Исходные данные:
- предмет: {{ПРЕДМЕТ}};
- класс: {{КЛАСС}};
- тема: {{ТЕМА}};
- учебная цель: {{ЦЕЛЬ}};
- язык результата: {{ЯЗЫК}}.

Сделай результат понятным начинающему учителю и пригодным для практического использования.
Соблюдай условие: Приложены исходная версия, список найденных ошибок, исправленная карточка и отметка о ручной проверке фактов.
Не используй реальные имена, контакты, фотографии, оценки или другие персональные данные учащихся.
```

Ф — Формат:
Сначала дай готовый результат, затем короткую инструкцию по применению и блок самопроверки. Соблюдай обязательное условие: Приложены исходная версия, список найденных ошибок, исправленная карточка и отметка о ручной проверке фактов.

Мына шартты сақта: Бастапқы нұсқа, табылған қателер тізімі, түзетілген карточка және фактілерді қолмен тексеру белгісі қоса беріледі.

2. Расталмаған фактілерді қоспа.
3. Қысқа әрі түсінікті тұжырымдар жаз.
4. Әр элементтің оқу мақсатымен тікелей байланысын сақта.

Төмендегі бастапқы нұсқаны пәндік редактор және деректер қауіпсіздігі маманы ретінде тексер.

**Когда применять / Қашан қолдану:** Бастапқы нұсқа және орындалуы тиіс ескертулер немесе өлшемдер бар кезде.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}
