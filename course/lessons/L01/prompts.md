# L01: Объяснение своими словами / Өз сөзімен түсіндіру

## Русский

### P-L01-01

**Эквивалент / Баламасы:** P-L01-07

**Назначение / Мақсаты:** Быстро получить первый вариант результата урока «Объяснение своими словами».

**Когда применять / Қашан қолдану:** В начале работы, чтобы получить черновик и увидеть, каких уточнений не хватает.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Первый структурированный вариант: краткое объяснение темы своими словами для начинающего учителя.

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Результат соответствует теме и цели; обязательное условие: Объяснение содержит 120–180 слов, один понятный пример, одну аналогию и не копирует исходную формулировку.

```text
Создай краткое объяснение темы своими словами для начинающего учителя.

Исходные данные:
- предмет: {{ПРЕДМЕТ}};
- класс: {{КЛАСС}};
- тема: {{ТЕМА}};
- учебная цель: {{ЦЕЛЬ}};
- язык результата: {{ЯЗЫК}}.

Сделай результат понятным начинающему учителю и пригодным для практического использования.
Соблюдай условие: Объяснение содержит 120–180 слов, один понятный пример, одну аналогию и не копирует исходную формулировку.
Не используй реальные имена, контакты, фотографии, оценки или другие персональные данные учащихся.
```

```text
Сначала дай готовый результат, затем короткую инструкцию по применению и блок самопроверки. Соблюдай обязательное условие: Объяснение содержит 120–180 слов, один понятный пример, одну аналогию и не копирует исходную формулировку.
```

```text
Обязательное требование урока: Объяснение содержит 120–180 слов, один понятный пример, одну аналогию и не копирует исходную формулировку.
Не включай персональные данные учащихся.
```

### P-L01-10

**Эквивалент / Баламасы:** P-L01-04

**Назначение / Мақсаты:** Алдын ала берілген шектеулер мен өлшемдерге сай басқарылатын нәтиже алу.

**Когда применять / Қашан қолдану:** Дәлдік, көлем, құрылым және қауіпсіздік маңызды болған соңғы генерация алдында.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Шектеулер бойынша ішкі тексеруден өткен нәтиже: тақырыпты бастаушы мұғалімге өз сөзімен қысқаша түсіндіру.

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Барлық шектеу орындалып, қорытынды чек-листе анық белгіленген.

```text
Мына деректер бойынша тақырыпты бастаушы мұғалімге өз сөзімен қысқаша түсіндіру дайында:
- пән: {{ПРЕДМЕТ}};
- сынып: {{КЛАСС}};
- тақырып: «{{ТЕМА}}»;
- мақсат: «{{ЦЕЛЬ}}»;
- тіл: {{ЯЗЫК}}.

Шектеулер:
1. Білім алушылардың дербес деректерін қолданба.
2. Расталмаған фактілерді қоспа.
3. Қысқа әрі түсінікті тұжырымдар жаз.
4. Әр элементтің оқу мақсатымен тікелей байланысын сақта.
5. Арнайы шартты орында: Түсіндіру 120–180 сөзден, бір түсінікті мысалдан және бір ұқсатудан тұрады әрі бастапқы тұжырымды көшірмейді.

Нәтижені бермес бұрын оны бес шектеу бойынша тексер. Нәтижеден кейін «өлшем — орындалды/түзету керек — түсініктеме» кестесін қос.
```

### P-L01-11

**Эквивалент / Баламасы:** P-L01-05

**Назначение / Мақсаты:** Практикалық жұмысты тапсырар алдында жасалған материалды тексеру.

**Когда применять / Қашан қолдану:** Бастапқы нұсқа жасалғаннан кейін және қорытынды файлды, сілтемені, скриншотты немесе мәтінді сақтар алдында.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Материалды толық қайта жазбай, нақты қателер, тәуекелдер және қажетті түзетулер тізімін алу.

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Әр ескерту материалдың нақты бөлігімен байланысып, тексерілетін ұсыныс береді.

```text
Төмендегі бастапқы нұсқаны пәндік редактор және деректер қауіпсіздігі маманы ретінде тексер.

Тексеру контексті:
- пән: {{ПРЕДМЕТ}};
- сынып: {{КЛАСС}};
- тақырып: {{ТЕМА}};
- мақсат: {{ЦЕЛЬ}};
- тіл: {{ЯЗЫК}};
- нәтиже түрі: тақырыпты бастаушы мұғалімге өз сөзімен қысқаша түсіндіру;
- міндетті шарт: Түсіндіру 120–180 сөзден, бір түсінікті мысалдан және бір ұқсатудан тұрады әрі бастапқы тұжырымды көшірмейді.

БАСТАПҚЫ НҰСҚА:
[ЖАСАЛҒАН МАТЕРИАЛДЫ НЕМЕСЕ ОНЫҢ МӘТІНДІК СИПАТТАМАСЫН ОСЫНДА ҚОЙЫҢЫЗ]

Мыналарды тексер:
1. пәндік дәлдік;
2. сынып пен мақсатқа сәйкестік;
3. міндетті шарттың толық орындалуы;
4. нұсқаулардың түсініктілігі;
5. дербес деректердің болмауы;
6. мұғалім қолмен тексеруі тиіс фактілер.

Жауапты «үзінді — мәселе — неліктен маңызды — нақты түзету» кестесімен бер. Соңында «дайын», «түзетуден кейін дайын» немесе «қайта өңдеу қажет» деген шешім шығар.
```

### P-L01-12

**Эквивалент / Баламасы:** P-L01-06

**Назначение / Мақсаты:** Сәтті бөліктерді сақтай отырып, тексеру нәтижесі бойынша материалды жетілдіру.

**Когда применять / Қашан қолдану:** Бастапқы нұсқа және орындалуы тиіс ескертулер немесе өлшемдер бар кезде.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Түзетілген қорытынды нұсқа: тақырыпты бастаушы мұғалімге өз сөзімен қысқаша түсіндіру, сондай-ақ өзгерістер журналы.

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Барлық маңызды ескерту түзетіліп, өзгерістер бастапқы нұсқамен салыстырылады.

```text
{{ПРЕДМЕТ}} пәні, {{КЛАСС}} сынып, «{{ТЕМА}}» тақырыбы, «{{ЦЕЛЬ}}» мақсаты үшін {{ЯЗЫК}} тіліндегі материалды жетілдір.

Материал түрі: тақырыпты бастаушы мұғалімге өз сөзімен қысқаша түсіндіру.
Міндетті шарт: Түсіндіру 120–180 сөзден, бір түсінікті мысалдан және бір ұқсатудан тұрады әрі бастапқы тұжырымды көшірмейді.

БАСТАПҚЫ НҰСҚА:
[БАСТАПҚЫ МАТЕРИАЛДЫ ҚОЙЫҢЫЗ]

ЕСКЕРТУЛЕР:
[ТЕКСЕРУ НӘТИЖЕСІН НЕМЕСЕ ӨЗ ПІКІРЛЕРІҢІЗДІ ҚОЙЫҢЫЗ]

Сәтті бөліктерді сақта, тек негізделген кемшіліктерді түзет, дербес деректерді алып таста және фактілерді қолмен тексеру қажет жерлерді белгіле. Алдымен толық дайын нұсқаны, содан кейін «бұрын — кейін — себеп» форматындағы өзгерістер журналын және мақсатқа сәйкестік бойынша қорытынды чек-листі бер.
```
