# L04: Улучшение запроса по Р-З-К-Ф / Сұрауды Р-З-К-Ф бойынша жақсарту

## Русский

### P-L04-01

**Эквивалент / Баламасы:** P-L04-07

**Назначение / Мақсаты:** Быстро получить первый вариант результата урока «Улучшение запроса по Р-З-К-Ф».

**Когда применять / Қашан қолдану:** В начале работы, чтобы получить черновик и увидеть, каких уточнений не хватает.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Первый структурированный вариант: цепочку «слабый запрос → Р-З-К-Ф → улучшенный результат».

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Результат соответствует теме и цели; обязательное условие: Показаны все четыре компонента: роль, задача, контекст и формат, а также заметное различие результатов.

```text
Создай цепочку «слабый запрос → Р-З-К-Ф → улучшенный результат».

Исходные данные:
- предмет: {{ПРЕДМЕТ}};
- класс: {{КЛАСС}};
- тема: {{ТЕМА}};
- учебная цель: {{ЦЕЛЬ}};
- язык результата: {{ЯЗЫК}}.

Сделай результат понятным начинающему учителю и пригодным для практического использования.
Соблюдай условие: Показаны все четыре компонента: роль, задача, контекст и формат, а также заметное различие результатов.
Не используй реальные имена, контакты, фотографии, оценки или другие персональные данные учащихся.
```

### P-L04-02

**Эквивалент / Баламасы:** P-L04-08

**Назначение / Мақсаты:** Сформулировать подробный запрос по модели Р-З-К-Ф: роль, задача, контекст, формат.

**Когда применять / Қашан қолдану:** Когда базовый запрос дал слишком общий или плохо структурированный ответ.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Практически готовый и логично оформленный результат: цепочку «слабый запрос → Р-З-К-Ф → улучшенный результат».

**Критерий хорошего ответа / Жақсы жауап өлшемі:** В ответе учтены роль, конкретная задача, учебный контекст и требуемый формат.

```text
Р — Роль:
Ты опытный методист и предметный учитель, который создаёт материалы для начинающих педагогов.

З — Задача:
Подготовь цепочку «слабый запрос → Р-З-К-Ф → улучшенный результат» по предмету {{ПРЕДМЕТ}} для {{КЛАСС}} класса на тему «{{ТЕМА}}».

К — Контекст:
Учебная цель — {{ЦЕЛЬ}}. Материал будет использован учителем в реальном занятии. Язык — {{ЯЗЫК}}. Учащиеся не должны быть идентифицируемы. Не добавляй реальные персональные данные и не выдумывай факты, которые требуют внешней проверки.

Ф — Формат:
Сначала дай готовый результат, затем короткую инструкцию по применению и блок самопроверки. Соблюдай обязательное условие: Показаны все четыре компонента: роль, задача, контекст и формат, а также заметное различие результатов.
```

### P-L04-03

**Эквивалент / Баламасы:** P-L04-09

**Назначение / Мақсаты:** Адаптировать результат к конкретному предмету, классу и учебной теме.

**Когда применять / Қашан қолдану:** Когда нужен не универсальный шаблон, а предметный материал для занятия.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Предметно точный вариант: цепочку «слабый запрос → Р-З-К-Ф → улучшенный результат», связанный с учебной целью.

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Содержание проверяет или объясняет именно заявленный навык, а не только упоминает тему.

```text
Работай как учитель предмета {{ПРЕДМЕТ}}. Создай цепочку «слабый запрос → Р-З-К-Ф → улучшенный результат» для {{КЛАСС}} класса по теме «{{ТЕМА}}» на языке {{ЯЗЫК}}.

Цель занятия: {{ЦЕЛЬ}}.

Используй корректные предметные термины, один конкретный учебный пример и действия, соответствующие возрасту класса. Покажи, как созданный материал помогает достичь цели. Добавь краткий ответ или ориентир для проверки там, где это уместно.

Обязательное требование урока: Показаны все четыре компонента: роль, задача, контекст и формат, а также заметное различие результатов.
Не включай персональные данные учащихся.
```

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Все ограничения выполнены и явно отмечены в итоговом чек-листе.

```text
Подготовь цепочку «слабый запрос → Р-З-К-Ф → улучшенный результат» для:

- цели «{{ЦЕЛЬ}}»;
- языка {{ЯЗЫК}}.

1. Не используй персональные данные учащихся.
2. Не добавляй неподтверждённые факты.

4. Сохраняй прямую связь каждого элемента с учебной целью.
5. Соблюдай специальное условие: Показаны все четыре компонента: роль, задача, контекст и формат, а также заметное различие результатов.

Перед выдачей результата проверь его по пяти ограничениям. После результата добавь таблицу: «критерий — выполнено/нужно исправить — комментарий».
```

```text
Ответ дай таблицей: «фрагмент — проблема — почему это важно — точное исправление». В конце вынеси решение: «готово», «готово после исправлений» или «требует переработки».
```

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Нәтиже тақырып пен мақсатқа сәйкес келеді; міндетті шарт: Төрт компоненттің бәрі көрсетіледі: рөл, міндет, контекст және формат; нәтижелердің айқын айырмасы беріледі.

```text
«әлсіз сұрау → р-з-к-ф → жақсартылған нәтиже» тізбегін жаса.

- пән: {{ПРЕДМЕТ}};
- сынып: {{КЛАСС}};

- оқу мақсаты: {{ЦЕЛЬ}};

Нәтижені бастаушы мұғалімге түсінікті және тәжірибеде қолдануға жарамды етіп жаса.
Мына шартты сақта: Төрт компоненттің бәрі көрсетіледі: рөл, міндет, контекст және формат; нәтижелердің айқын айырмасы беріледі.
Білім алушылардың нақты аты-жөнін, байланыс деректерін, фотосуреттерін, бағаларын немесе өзге дербес деректерін қолданба.
```

### P-L04-08

**Эквивалент / Баламасы:** P-L04-02

**Назначение / Мақсаты:** Р-З-К-Ф үлгісі бойынша толық сұрау құру: рөл, міндет, контекст, формат.

**Когда применять / Қашан қолдану:** Базалық сұрау тым жалпы немесе нашар құрылымдалған жауап берген кезде.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Логикалық рәсімделген, іс жүзінде қолдануға дайын нәтиже: «әлсіз сұрау → Р-З-К-Ф → жақсартылған нәтиже» тізбегін.

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Жауапта рөл, нақты міндет, оқу контексті және қажетті формат ескерілген.

```text
Р — Рөл:
Сен бастаушы педагогтерге материал әзірлейтін тәжірибелі әдіскер және пән мұғалімісің.

З — Задача/міндет:
{{ПРЕДМЕТ}} пәні бойынша {{КЛАСС}} сыныпқа «{{ТЕМА}}» тақырыбында «әлсіз сұрау → Р-З-К-Ф → жақсартылған нәтиже» тізбегін дайында.

К — Контекст:
Оқу мақсаты — {{ЦЕЛЬ}}. Материалды мұғалім нақты сабақта қолданады. Тілі — {{ЯЗЫК}}. Білім алушыларды сәйкестендіруге болмайды. Нақты дербес деректерді қоспа және сыртқы тексеруді қажет ететін фактілерді ойдан шығарма.

Ф — Формат:
Алдымен дайын нәтижені, содан кейін қысқа қолдану нұсқаулығын және өзін-өзі тексеру блогын бер. Міндетті шартты сақта: Төрт компоненттің бәрі көрсетіледі: рөл, міндет, контекст және формат; нәтижелердің айқын айырмасы беріледі.
```

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Мазмұн тақырыпты жай ғана атамай, көрсетілген дағдыны түсіндіреді немесе тексереді.

```text

Сабақтың міндетті талабы: Төрт компоненттің бәрі көрсетіледі: рөл, міндет, контекст және формат; нәтижелердің айқын айырмасы беріледі.
```

### P-L04-10
