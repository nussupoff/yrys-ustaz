# L24: Презентация из описания / Сипаттамадан жасалған презентация

## Русский

### P-L24-01

**Эквивалент / Баламасы:** P-L24-07

**Назначение / Мақсаты:** Быстро получить первый вариант результата урока «Презентация из описания».

**Когда применять / Қашан қолдану:** В начале работы, чтобы получить черновик и увидеть, каких уточнений не хватает.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Первый структурированный вариант: презентацию, созданную из подробного текстового описания.

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Результат соответствует теме и цели; обязательное условие: Приложены исходное описание и итоговая презентация; структура, стиль и содержание соответствуют описанию.

```text
Создай презентацию, созданную из подробного текстового описания.

Исходные данные:
- предмет: {{ПРЕДМЕТ}};
- класс: {{КЛАСС}};
- тема: {{ТЕМА}};
- учебная цель: {{ЦЕЛЬ}};
- язык результата: {{ЯЗЫК}}.

Сделай результат понятным начинающему учителю и пригодным для практического использования.
Соблюдай условие: Приложены исходное описание и итоговая презентация; структура, стиль и содержание соответствуют описанию.
Не используй реальные имена, контакты, фотографии, оценки или другие персональные данные учащихся.
```

### P-L24-02

**Эквивалент / Баламасы:** P-L24-08

**Назначение / Мақсаты:** Сформулировать подробный запрос по модели Р-З-К-Ф: роль, задача, контекст, формат.

**Когда применять / Қашан қолдану:** Когда базовый запрос дал слишком общий или плохо структурированный ответ.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Практически готовый и логично оформленный результат: презентацию, созданную из подробного текстового описания.

**Критерий хорошего ответа / Жақсы жауап өлшемі:** В ответе учтены роль, конкретная задача, учебный контекст и требуемый формат.

```text
Р — Роль:
Ты опытный методист и предметный учитель, который создаёт материалы для начинающих педагогов.

З — Задача:
Подготовь презентацию, созданную из подробного текстового описания по предмету {{ПРЕДМЕТ}} для {{КЛАСС}} класса на тему «{{ТЕМА}}».

К — Контекст:
Учебная цель — {{ЦЕЛЬ}}. Материал будет использован учителем в реальном занятии. Язык — {{ЯЗЫК}}. Учащиеся не должны быть идентифицируемы. Не добавляй реальные персональные данные и не выдумывай факты, которые требуют внешней проверки.

Ф — Формат:
Сначала дай готовый результат, затем короткую инструкцию по применению и блок самопроверки. Соблюдай обязательное условие: Приложены исходное описание и итоговая презентация; структура, стиль и содержание соответствуют описанию.
```

### P-L24-03

**Назначение / Мақсаты:** Адаптировать результат к конкретному предмету, классу и учебной теме.

**Когда применять / Қашан қолдану:** Когда нужен не универсальный шаблон, а предметный материал для занятия.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Предметно точный вариант: презентацию, созданную из подробного текстового описания, связанный с учебной целью.

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Содержание проверяет или объясняет именно заявленный навык, а не только упоминает тему.

```text
Работай как учитель предмета {{ПРЕДМЕТ}}. Создай презентацию, созданную из подробного текстового описания для {{КЛАСС}} класса по теме «{{ТЕМА}}» на языке {{ЯЗЫК}}.

Цель занятия: {{ЦЕЛЬ}}.

Используй корректные предметные термины, один конкретный учебный пример и действия, соответствующие возрасту класса. Покажи, как созданный материал помогает достичь цели. Добавь краткий ответ или ориентир для проверки там, где это уместно.

Обязательное требование урока: Приложены исходное описание и итоговая презентация; структура, стиль и содержание соответствуют описанию.
Не включай персональные данные учащихся.
```

```text
Перед выдачей результата проверь его по пяти ограничениям. После результата добавь таблицу: «критерий — выполнено/нужно исправить — комментарий».
```

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Каждое замечание связано с фрагментом материала и содержит проверяемую рекомендацию.

```text
Проверь приведённый ниже черновик как предметный редактор и специалист по безопасности данных.

- тема: {{ТЕМА}};
- цель: {{ЦЕЛЬ}};
- язык: {{ЯЗЫК}};

- обязательное условие: Приложены исходное описание и итоговая презентация; структура, стиль и содержание соответствуют описанию.

ЧЕРНОВИК:

Проверь:
1. предметную точность;
2. соответствие классу и цели;
3. полноту обязательного условия;
4. понятность инструкций;
5. отсутствие персональных данных;
6. факты, которые учителю нужно проверить вручную.

Ответ дай таблицей: «фрагмент — проблема — почему это важно — точное исправление». В конце вынеси решение: «готово», «готово после исправлений» или «требует переработки».
```

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Нәтиже тақырып пен мақсатқа сәйкес келеді; міндетті шарт: Бастапқы сипаттама мен қорытынды презентация қоса беріледі; құрылым, стиль және мазмұн сипаттамаға сәйкес болады.

```text
Егжей-тегжейлі мәтіндік сипаттамадан жасалған презентацияны жаса.

- пән: {{ПРЕДМЕТ}};
- сынып: {{КЛАСС}};
- тақырып: {{ТЕМА}};
- оқу мақсаты: {{ЦЕЛЬ}};
- нәтиже тілі: {{ЯЗЫК}}.

Нәтижені бастаушы мұғалімге түсінікті және тәжірибеде қолдануға жарамды етіп жаса.
Мына шартты сақта: Бастапқы сипаттама мен қорытынды презентация қоса беріледі; құрылым, стиль және мазмұн сипаттамаға сәйкес болады.
Білім алушылардың нақты аты-жөнін, байланыс деректерін, фотосуреттерін, бағаларын немесе өзге дербес деректерін қолданба.
```

**Ожидаемый результат / Күтілетін нәтиже:** Шектеулер бойынша ішкі тексеруден өткен нәтиже: егжей-тегжейлі мәтіндік сипаттамадан жасалған презентацияны.

```text
Мына деректер бойынша егжей-тегжейлі мәтіндік сипаттамадан жасалған презентацияны дайында:

- тақырып: «{{ТЕМА}}»;

Шектеулер:
1. Білім алушылардың дербес деректерін қолданба.
2. Расталмаған фактілерді қоспа.
3. Қысқа әрі түсінікті тұжырымдар жаз.
4. Әр элементтің оқу мақсатымен тікелей байланысын сақта.
```

### P-L24-11

**Эквивалент / Баламасы:** P-L24-05

**Назначение / Мақсаты:** Практикалық жұмысты тапсырар алдында жасалған материалды тексеру.

**Когда применять / Қашан қолдану:** Бастапқы нұсқа жасалғаннан кейін және қорытынды файлды, сілтемені, скриншотты немесе мәтінді сақтар алдында.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Материалды толық қайта жазбай, нақты қателер, тәуекелдер және қажетті түзетулер тізімін алу.

**Критерий хорошего ответа / Жақсы жауап өлшемі:** Әр ескерту материалдың нақты бөлігімен байланысып, тексерілетін ұсыныс береді.

```text
Төмендегі бастапқы нұсқаны пәндік редактор және деректер қауіпсіздігі маманы ретінде тексер.

- пән: {{ПРЕДМЕТ}};

- тақырып: {{ТЕМА}};
- мақсат: {{ЦЕЛЬ}};
- тіл: {{ЯЗЫК}};
- нәтиже түрі: егжей-тегжейлі мәтіндік сипаттамадан жасалған презентацияны;
- міндетті шарт: Бастапқы сипаттама мен қорытынды презентация қоса беріледі; құрылым, стиль және мазмұн сипаттамаға сәйкес болады.
```

### P-L24-12

**Эквивалент / Баламасы:** P-L24-06

**Назначение / Мақсаты:** Сәтті бөліктерді сақтай отырып, тексеру нәтижесі бойынша материалды жетілдіру.

**Когда применять / Қашан қолдану:** Бастапқы нұсқа және орындалуы тиіс ескертулер немесе өлшемдер бар кезде.

**Что заменить / Нені ауыстыру керек:** {{ПРЕДМЕТ}}, {{КЛАСС}}, {{ТЕМА}}, {{ЦЕЛЬ}}, {{ЯЗЫК}}

**Ожидаемый результат / Күтілетін нәтиже:** Түзетілген қорытынды нұсқа: егжей-тегжейлі мәтіндік сипаттамадан жасалған презентацияны, сондай-ақ өзгерістер журналы.
